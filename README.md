# 🛒 SMORK E-COMMERCE STORE

A modern, high-quality **E-Commerce Frontend Web Application** built with a strong focus on **UI/UX, motion design, and real-world interaction flow**.

This project simulates a real shopping experience where users can browse products, preview items in detail, and instantly connect via WhatsApp to place orders.

---

## 🌟 Features

- 🖼 **Product Gallery (8 Items)** – Clean grid layout with responsive design  
- 🔍 **Image Lightbox Preview** – Click any product image to view it in full screen  
- 🛒 **Smart Add to Cart** – Triggers instant WhatsApp order flow  
- 💬 **WhatsApp Integration** – Opens chat with selected product automatically  
- 🎨 **Modern UI/UX** – Glassmorphism, motion effects, and smooth interactions  
- 📱 **Fully Responsive** – Works across mobile, tablet, and desktop  
- ⚡ **Fast Performance** – Lightweight and optimized frontend  

---

## 🛠 Tech Stack

- **HTML5**
- **Tailwind CSS**
- **Vanilla JavaScript**
- **Font Awesome Icons**

---

## 💡 How It Works

1. User browses products  
2. Clicks on an image → opens **lightbox preview**  
3. Clicks **Add to Cart**  
4. WhatsApp opens with a **pre-filled message**:
